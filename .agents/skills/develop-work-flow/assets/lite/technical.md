# lite TRD 模板入口

TRD 正文统一使用 [TRD：技术需求规格说明书模板](../feature/technical.md)，完整读取后再填写。本文件仅用于定位共用模板，不复制为业务项目的 `technical.md`。

按[主工作流的 TRD 模板规则](../../SKILL.md#trd-template)按实际需要组织内容，合并或省略无关章节，未变内容直接引用，并放置 lite 的 R、验收场景和其他工作流锚点。任务使用同目录 [plan.yaml](plan.yaml) 模板；仍只有 TRD＋PLAN 两份设计与计划源。

最末评审结论沿用共用模板，并按[评审状态规则](../../SKILL.md#document-review-status)填写。
