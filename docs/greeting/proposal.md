# greeting — 需求提案

> 状态: 已补齐 | 特征: 小需求

## 1. 功能概述

一个问候函数，接收用户名字，返回中文问候语。

## 2. 接口规格

```
greet(name: String) → String
```

- **输入**: `name` — 用户名字
- **输出**: `"你好，{name}"` — 中文问候语

## 3. 异常边界

| # | 场景 | 输入 | 预期输出 |
|---|------|------|----------|
| 1 | 正常输入 | `"张三"` | `"你好，张三"` |
| 2 | 空字符串 | `""` | `"你好，匿名用户"` |
| 3 | `null` 输入 | `null` | `"你好，匿名用户"`（同空字符串处理） |
| 4 | 超长输入 | 长度 > 100 | 截断至前 100 字符后拼接问候语 |

## 4. 验收标准 (AC)

- AC1: 输入正常名字，返回带名字的问候语
- AC2: 输入空字符串，返回默认 "匿名用户" 问候语
- AC3: 输入 `null`，返回默认 "匿名用户" 问候语
- AC4: 输入超过 100 字符，自动截断至 100 字符后拼接问候语
- AC5: 函数为纯函数，无副作用
